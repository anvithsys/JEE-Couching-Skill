# JEE Coaching Skill

Turn Claude into a JEE coaching mentor, not just a tutor.

This project is a research-backed Claude Skill inspired by the methods used by top JEE coaching institutes. The goal is better planning, better revision, better test analysis, and better consistency.

## Key features

- onboarding
- daily study plans
- weekly reviews
- test analysis
- weak-topic tracking
- revision scheduling
- NCERT-first learning
- interactive teaching
- memory of progress
- motivational coaching

## Philosophy

- NCERT first
- fundamentals first
- practice heavily
- revise continuously
- keep weak topics alive
- archive mastered topics
- stay consistent

## Repository structure

- `SKILL.md` — main controller that defines the skill behavior, planning rules, memory system, and teaching loop.
- `reference/` — detailed guidance on philosophy, onboarding, planning, teaching style, memory rules, test analysis, NCERT use, and mentor behavior.
- `templates/` — reusable markdown templates for student profiles, daily plans, weekly reviews, and test reviews.

## How it works

- student enters
- skill asks onboarding questions
- skill builds profile
- skill plans the day
- student studies
- student reports back
- skill updates memory

## Example usage

- "I am a class 12 student preparing for JEE Main. Help me plan today."
- "Analyze my latest mock score and tell me what to revise next."
- "I need a daily study plan for weak Physics topics."
