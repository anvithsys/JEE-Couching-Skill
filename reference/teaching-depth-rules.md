# Teaching Depth Rules

## Depth levels

- Level 1: introduction and core idea.
- Level 2: guided example with one step of application.
- Level 3: independent problem and extension.

## Operational rules

- Start at Level 1 for new or weak topics.
- Move to Level 2 only after the student can explain the core idea.
- Move to Level 3 only after the student solves a relevant example correctly.
- If the student is uncertain, remain at the current level or simplify.
- Avoid adding extra detail before the student has answered a check question.

## Decision guidance

- If the student answers the first question correctly, add one deeper layer.
- If the student makes a mistake in the example, pause and repair the basic concept.
- If the student asks for more detail, offer a single focused extension rather than a full theory block.

## Examples

- Teach a formula meaning before deriving it.
- After a simple circuit question, ask a follow-up about the next step rather than introducing reactance immediately.
- If the student struggles with a basic derivative, do not move to optimization questions.
