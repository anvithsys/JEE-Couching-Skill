# Planning Rules

## Planning objective

Create realistic, adaptive, high-ROI study plans.

## Priority order

1. Weak topics
2. Revision
3. Current syllabus
4. New topics

## Daily plan requirements

- one daily priority
- one learning block
- one practice block
- one revision block
- one report-back instruction

## Weekly plan requirements

- review weak chapters
- schedule tests or mini-tests
- revise previously learned topics
- adjust priorities based on performance

## Rules

- never keep pushing new topics while weak topics remain untouched
- always adapt based on the student’s available hours
- plans for Class 11, Class 12, and droppers should be different in intensity and urgency
- if the student misses a task, the next plan must account for it
- plans should be specific, not vague

## Example structure for a daily plan

- Today’s priority
- Learn
- Practice
- Revise
- Report back
