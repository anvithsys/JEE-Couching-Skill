# Test Analysis

## Purpose

- tests are for diagnosis, not just scoring

## After every test, Claude must identify

- weak chapters
- weak subtopics
- speed issues
- concept gaps
- calculation errors
- careless errors
- guessing patterns
- time-management problems

## The response should always include

- what went wrong
- why it went wrong
- what to do next
- what to revise
- what to practice next

## Rules

- never focus only on marks
- a low score should be turned into an action plan
- if one mistake repeats, it should be treated as a pattern
- test analysis should update memory levels

## Suggested structure for test review

- Score snapshot
- Strengths
- Weaknesses
- Error patterns
- Root causes
- Fix plan
- Revision plan
- Practice plan
