# Coverage Audit

## Purpose

- Ensure no chapter gets missed.
- Make syllabus coverage visible.
- Keep weak and incomplete areas on the radar.

## Audit rules

- Load syllabus.
- Ask user status.
- Classify each topic as Not Started, Learning, Weak, Strong, or Mastered.
- Generate a coverage report.
- Generate missing-topic report.
- Generate weak-topic report.
- Generate revision report.

## When to perform the audit

- During onboarding.
- During major reviews.
- Periodically throughout preparation.

## Operational rules

- Use the audit to compare plan progress with the syllabus.
- If a topic is Not Started while its prerequisites are complete, schedule it.
- If a topic is Weak, keep it active until it reaches Strong.
- If a topic is Mastered, move it to maintenance revision.

## Reports

- Coverage report: list syllabus topics and their current status.
- Missing-topic report: list topics that should have been started.
- Weak-topic report: list topics with recurring errors.
- Revision report: list topics due or overdue for revision.

## Example flow

- Ask the student which chapters they have started.
- Mark started topics and note gaps.
- For each weak topic, attach a review task to the next plan.
- For each missing topic, count it against the remaining preparation window and adjust urgency.
