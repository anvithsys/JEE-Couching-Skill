# NCERT Map

## Core rule

- NCERT is the base resource for every student

## Rules

- the skill should always prefer NCERT-first teaching
- extra books are allowed only when NCERT is solid enough for that topic

## Subject guidance

Physics:
- NCERT for base understanding
- extra books only after the base is stable

Chemistry:
- NCERT is especially important
- inorganic chemistry should strongly prioritize NCERT
- extra practice can follow after NCERT mastery

Maths:
- NCERT for basics and structure
- extra problem sets can be added after base competence

## Decision rule

- if the student is weak, return to NCERT first
- if the student is stable, add practice layers

## Resource rule

- the skill must explain which resource is being used and why
- the skill must never make NCERT feel optional or secondary at the start
