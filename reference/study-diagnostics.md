# Study Diagnostics

## Purpose

- Diagnose why a student is struggling.
- Translate symptoms into interventions.
- Keep coaching operational and targeted.

## Possible causes

### Knowledge gap

- Symptoms: repeated mistake on the same concept, inability to explain basic steps.
- Questions Claude should ask:
  - "Can you tell me the main idea behind this topic?"
  - "Which step felt unclear?"
- Possible interventions:
  - return to the core concept
  - use a simpler example
  - assign a focused concept checklist

### Weak prerequisite

- Symptoms: correct current-level reasoning but failure on foundational steps.
- Questions Claude should ask:
  - "What earlier topic connects to this problem?"
  - "Can you solve the simpler precursor case?"
- Possible interventions:
  - pause and review prerequisite material
  - map dependencies before continuing
  - add a brief prerequisite warm-up

### Lack of revision

- Symptoms: remembered today, forgotten later; accuracy drops on repeated exposure.
- Questions Claude should ask:
  - "When did you last review this topic?"
  - "Can you recall the key formula without looking?"
- Possible interventions:
  - schedule spaced revision
  - use recall-based review blocks
  - mark the topic as weak and raise its priority

### Poor problem volume

- Symptoms: concept appears correct but practice speed and flexibility are low.
- Questions Claude should ask:
  - "How many problems did you solve on this topic?"
  - "Did you practice different question patterns?"
- Possible interventions:
  - increase targeted practice count
  - mix beginner and intermediate problems
  - add timed practice if speed is the issue

### Time management

- Symptoms: many unfinished problems, rushed answers, low completion within allotted hours.
- Questions Claude should ask:
  - "How much time did you spend on each question?"
  - "Where did you lose time?"
- Possible interventions:
  - add timed checkpoints
  - break practice into smaller sessions
  - teach efficient problem selection and scanning

### Careless mistakes

- Symptoms: correct understanding but avoidable calculation or sign errors.
- Questions Claude should ask:
  - "What did you check after solving the question?"
  - "Did you re-read the question carefully?"
- Possible interventions:
  - add a review step after each solution
  - train error-checking habits
  - include one accuracy-focused problem in each practice block

### Burnout

- Symptoms: low focus, skipped sessions, flat responses.
- Questions Claude should ask:
  - "How are you feeling about the study load?"
  - "Are you getting enough rest?"
- Possible interventions:
  - reduce volume temporarily
  - keep sessions short and high-value
  - focus on one clear task and restore routine

### Avoidance

- Symptoms: delaying weak topics, wanting only easy material.
- Questions Claude should ask:
  - "Which topic do you keep putting off?"
  - "What makes that topic feel hard?"
- Possible interventions:
  - assign a small concrete step on the avoided topic
  - schedule it early in the next session
  - acknowledge the avoidance and keep the plan firm

### Fear of difficulty

- Symptoms: reluctance to attempt harder problems, over-reliance on simple examples.
- Questions Claude should ask:
  - "What does this question feel like?"
  - "What part seems unfamiliar?"
- Possible interventions:
  - choose a low-risk but meaningful problem
  - break the question into two or three tiny parts
  - reinforce the basic idea before challenging practice
