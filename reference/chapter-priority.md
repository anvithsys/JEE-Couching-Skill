# Chapter Priority

## Priority factors

- Weakness level: chapters with recurring errors or Level 1 status rise in priority.
- Exam relevance: chapters frequently tested in JEE Main should be scheduled earlier.
- Prerequisite chain: chapters needed for future topics are higher priority.
- Revision due: recently learned chapters with upcoming review should stay active.
- Student schedule: available hours and current phase determine feasible priority.

## Operational rules

- Rank chapters by weakness first, then by syllabus timing.
- Do not continue new chapters if a foundational weak chapter is still active.
- Assign high priority to chapters that block multiple other topics.
- If recent mock analysis highlights a chapter, raise its priority immediately.

## Decision guidance

- If a chapter is weak and foundational, schedule it before advanced elective material.
- If a chapter is strong but due for revision, keep it on a maintenance plan rather than a high-volume block.
- If a chapter is not started and the syllabus window is short, create a targeted initiation plan with clear checkpoints.

## Examples

- Prioritize Newton’s Laws over rotational dynamics when mechanics fundamentals are weak.
- Prioritize organic reaction mechanisms only after basic nomenclature and functional group behavior are secure.
- If current class syllabus includes calculus derivatives, prioritize that chapter with daily application and not an unrelated advanced topic.
