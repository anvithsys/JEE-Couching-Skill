# Learning Science

## Active Recall

- What it is: forcing a student to retrieve information from memory.
- Why it works: strengthens memory retrieval pathways and exposes gaps.
- How Claude should use it: ask students to explain concepts, solve problems, and recall formulas without prompts.
- How it affects planning: include recall questions after every learning block.
- How it affects teaching: avoid giving answers too quickly; make the student produce the first step.

## Retrieval Practice

- What it is: repeated testing of the same idea.
- Why it works: improves retention and highlights weak points.
- How Claude should use it: add short quizzes, flash questions, and problem prompts in sessions.
- How it affects planning: schedule mini-checkpoints during the same day and the next day.
- How it affects teaching: use quick follow-up questions after examples.

## Spaced Repetition

- What it is: revisiting material at increasing intervals.
- Why it works: combats forgetting by reinforcing memory just before decay.
- How Claude should use it: create spaced review blocks for topics after learning, a few days later, one week later, and later.
- How it affects planning: embed repetition schedules into daily and weekly plans.
- How it affects teaching: revisit prior topics with targeted questions, not full re-teaching.

## Interleaving

- What it is: alternating related topics or problem types.
- Why it works: builds discrimination and flexible application.
- How Claude should use it: mix questions from different chapters in practice sessions.
- How it affects planning: avoid long single-topic blocks when a student is preparing for a mixed exam.
- How it affects teaching: present varied problems that require switching strategy.

## Deliberate Practice

- What it is: focused practice on weak areas with feedback.
- Why it works: drives improvement where it matters most.
- How Claude should use it: assign problems targeted to the student’s weak chapters and review mistakes immediately.
- How it affects planning: prioritize weak-topic practice and place it early in the study session.
- How it affects teaching: do not treat all problems equally; label some as deliberate practice.

## Error-Based Learning

- What it is: learning from mistakes by analyzing why they happened.
- Why it works: turns errors into useful information.
- How Claude should use it: ask the student to explain their mistakes and compare wrong vs right reasoning.
- How it affects planning: allocate time for error review after practice and tests.
- How it affects teaching: use incorrect student responses as teaching moments.

## Cognitive Load Management

- What it is: keeping working memory demands manageable.
- Why it works: prevents confusion and improves learning efficiency.
- How Claude should use it: split complex ideas into smaller chunks and avoid long multi-step explanations.
- How it affects planning: limit new material in one session and include checkpoints.
- How it affects teaching: use simple examples, clear structure, and step-by-step guidance.
