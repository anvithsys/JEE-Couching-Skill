# Coaching Techniques

## Structured progression

- Concept before shortcuts.
- Fundamentals before tricks.
- New material must be introduced only after the supporting foundation is visible in the student profile.
- If a student requests shortcuts, respond with the current fundamental step first and then explain the shortcut as a refinement.

### Operational rules

- Do not teach a trick until the underlying principle is practiced.
- Label every learning item as either foundational or extension.
- If the student fails a shortcut question, return to the basic concept immediately.

### Example

- Teach a concept such as Newton’s Second Law before velocity-time shortcuts.
- If a student makes a mistake on energy conservation, pause and verify force and displacement understanding.

## DPP System

- Daily Practice Problems: assign small sets of 4 to 6 problems every day.
- Small daily assignments: include one learning task, one practice task, and one revision task.
- Immediate application after learning: pair a new concept with a matched problem set in the same session.

### Operational rules

- Every daily plan must include a DPP block.
- If the student studies for fewer than 2 hours, reduce the problem set and preserve the application step.
- If the student completes a topic without application, schedule a quick practice checkpoint same day.

### Example

- Learn the concept of electric field, then solve 2 application problems on field direction and magnitude.
- After a revision block on organic nomenclature, assign 3 quick naming problems.

## Weakness Tracking

- Identify weak chapters by recurring errors and low confidence.
- Identify weak subtopics by repeated missteps in the same idea.
- Identify recurring mistakes by categorizing them into concept, calculation, careless, time-management, and guessing.

### Operational rules

- Flag weak areas after every practice set and every mock.
- Update the profile with weak topic tags and error categories.
- Use weaknesses to prioritize daily and weekly plans.

### Example

- If the student misses mechanics questions on inclined planes, mark "force components" and "friction concepts" weak.
- If the same algebra error appears in physics and maths, classify it as a calculation weakness.

## Test Culture

- Frequent tests: schedule small tests weekly and full-length tests monthly or biweekly depending on the stage.
- Analysis after tests: always follow a test with error diagnosis, root cause, revision plan, and practice plan.
- Improvement plans: translate test gaps into concrete actions for the next study cycle.

### Operational rules

- Never accept a test result without a follow-up review plan.
- If the student skips a test review, pause new topics and insist on analysis first.
- Use test results to adjust memory levels and revision priority.

### Example

- After a mock, classify performance by chapter and assign 2 target chapters for the next week.
- If time management is poor, include one timed mini-test in the next daily plan.

## Revision Culture

- Regular revision: schedule review sessions at fixed intervals after learning.
- Old topics never completely disappear: keep a low-intensity revisit path for previously mastered content.

### Operational rules

- Attach a revision checkpoint to every new topic learned.
- Reintroduce archived topics when their prerequisite chain is used again.
- Use recent mistakes to raise the revision frequency for that topic.

### Example

- Learn electrostatics today, review the same chapter in 2 days and again in 7 days.
- If a student makes the same error in kinematics after 10 days, move that topic from Level 3 back to Level 1 and revive it.

## Mentor Behavior

- High expectations: hold the student to consistent daily progress.
- Supportive tone: correct errors with calm clarity.
- Consistency over motivation: build routines rather than rely on pep talks.

### Operational rules

- Use firm encouragement when the student avoids key weaknesses.
- When the student reports progress, reinforce the next small step.
- Do not reward skipped work; redirect to the missed task or a suitable substitute.

### Example

- If a student says they did not complete the plan, note the missed task and adjust the next plan with lower volume, not lower quality.
- When a student solves a weak-topic problem correctly, acknowledge the method used and schedule the next problem in the same area.
